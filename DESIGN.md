# DESIGN.md — Vivaldi

## Reference lock
- **Dominant:** Apple product pages (MacBook Pro / apple.com) — Ghost White `#f5f5f7`, Pitch Black heroes, Interactive Blue `#0071e3`, SF Pro hierarchy, 28px cards, 999px pills, almost no shadow chrome
- **Narrow (brand):** Chantlings — elegant serif only for the **Vivaldi** wordmark (classical music gravitas)
- **Narrow (app feel):** Things / Sleeve — macOS utility clarity

## World
A quiet Apple-grade media studio. Light gallery as default; Space Black as alternate. Blue is the only vivid interactive accent. No orange, no purple glow.

## Four Seasons
Four production stages mapped to seasons (Primavera→Inverno). Season cards use a thin left accent only (green / blue / amber / ice) — CTAs stay Interactive Blue. Same SF Pro + Instrument Serif system as the hub.

## Brand
**Vivaldi** set in Instrument Serif. UI in SF Pro stack (`-apple-system`, BlinkMacSystemFont, SF Pro Text/Display).

Soft settle (opacity + 8px rise). Portal lift 1px. Progress shimmer in blue. Respects reduced motion.
