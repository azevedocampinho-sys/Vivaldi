# PRODUCT.md — Vivaldi

## Product
Local media studio on localhost with four areas:
1. **YouTube** — batch download (MP4/MP3, resolution)
2. **Apple Music** — hygiene + local AI; one-click writes create cleaned/ordered playlists via official API
3. **Stems** — local HTDemucs stem separation (instrumental / full stems) for video editing
4. **Four Seasons** — music creation in 4 seasons (pré→pós), playlist DNA, humming, instruments, CIFRA/ABC

## Audience
Personal use by the owner on Apple Silicon (M4).

## Mode
Operate. Hub is Persuade-lite (choose a studio); each studio is task-focused.

## Constraints
- Gradio UI
- Apple Music: official API only, rate-limited, cached; no audio download/scrape
- AI: Ollama on-device by default
- Apple-premium visual system (Ghost White default, Interactive Blue, Instrument Serif wordmark)
